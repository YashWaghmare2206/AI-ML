# Crypto Price Analysis

This project collects 30 days of cryptocurrency price data using the CoinGecko API and performs basic analysis.

## Data Source
CoinGecko API

## Coins Analyzed
- Bitcoin
- Ethereum
- Solana
- Cardano

## Pipeline
API → JSON → Pandas → CSV → Analysis

## Key Insights
- Bitcoin showed the most price stability
- Solana showed the highest volatility
